# Project 2: The Server Commander

## About the Project

**The Server Commander** is a cloud computing project based on AWS EC2 and Linux server administration.

In this project, a Linux virtual server was launched on AWS EC2, accessed securely using SSH, configured through the Linux command line, and used to host a custom webpage.

## Project Goal

The goal of this project was to gain practical experience in:

* Cloud server deployment
* Linux server management
* SSH connectivity
* Web server installation
* AWS Security Group configuration
* Hosting a webpage on an EC2 instance

## Tools & Technologies

* **AWS EC2** – Cloud virtual machine
* **Linux** – Server operating system
* **SSH** – Secure remote server connection
* **Apache** – Web server
* **AWS Security Groups** – Network access control
* **Linux Terminal** – Server configuration

## Implementation

The project was completed through the following process:

1. Launched a Linux-based EC2 instance on AWS.
2. Configured the required Security Group rules.
3. Connected to the EC2 server using SSH.
4. Updated the server packages using Linux commands.
5. Installed the Apache web server.
6. Configured the web server to host a custom webpage.
7. Started and enabled the Apache service.
8. Accessed the webpage using the EC2 instance's public IP address.
9. Verified that the **"Welcome to DecodeLabs"** webpage was successfully displayed.

## Final Outcome

The AWS EC2 Linux server was successfully deployed and configured as a web server.

The server was accessed securely through SSH, Apache was installed and configured, and the custom **"Welcome to DecodeLabs"** webpage was successfully hosted and accessed through the EC2 public IP address.
